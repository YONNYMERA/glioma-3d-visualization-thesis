# Notebook histórico

`Training_model_original.ipynb` conserva el notebook original con salidas y
contadores de ejecución eliminados, y rutas personales sustituidas por variables
de referencia. No es la receta ejecutable del protocolo final ni se ejecuta como
parte del repositorio. Su evaluación por casos no acredita independencia entre
visitas del mismo paciente.

Para reproducir la comparación final use `cedia/README_CEDIA.md` y el manifiesto
por paciente. Los pesos históricos de la aplicación se distribuyen por separado
y no respaldan las métricas finales del benchmark.
